# wyrdhost

A mobile-first fantasy strategy game about commanding a persistent warband across
a dangerous campaign, inspired by Heroes of Might & Magic and Star Wars: Legion.
Build and customize your Companies, master Orders and tactical battles, an
survive long enough to overcome the campaign’s final threat.
